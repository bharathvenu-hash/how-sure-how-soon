**How Sure, How Soon: Communicating Uncertainty and Urgency in AI Health Self-Triage**
**Project Report by Bharath Badri Venugopalan, Student ID 3204674**

**SureSoon** is the prototype for my project *How Sure, How Soon*: a research prototype for AI health self-triage. 
It shows **how soon** to get care (urgency) and **how sure** the system is (certainty) as two separate signals. 
A language model, or a simulated stand-in, reads what the person says; fixed rules decide urgency.
